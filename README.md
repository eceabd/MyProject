# Restaurant E-Commerce Platform

A full-stack restaurant e-commerce platform built with the **MERN Stack**, featuring online shopping, secure user authentication, Stripe payment integration, and a dedicated admin dashboard.

## 🚀 Live Demo

- **Customer Store:** [Visit the Store](https://golden-pithivier-e9f8a1.netlify.app/)
- **Admin Dashboard:** [Visit Admin Panel](https://myproject-1-yrtl.onrender.com/admin/list)
- **GitHub Repository:** [MyProject](https://github.com/eceabd/MyProject)

## ✨ Features

### Customer Features
- User registration and login.
- Secure authentication and user protection.
- Browse and filter products by category.
- Add products to the shopping cart.
- Online payment integration using Stripe.
- Easy and user-friendly shopping experience.

### Admin Dashboard
- Dedicated admin dashboard.
- Manage users.
- Add, edit, and delete products.
- Manage and monitor customer orders.
- Control important store operations.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| MongoDB | Database |
| Express.js | Backend framework |
| React.js | Frontend library |
| Node.js | Backend runtime |
| Stripe | Online payment processing |

**Architecture:** MERN Stack (MongoDB, Express.js, React.js, Node.js).

## ⚙️ Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/eceabd/MyProject.git
   ```

2. Navigate into the project directory:

   ```bash
   cd MyProject
   ```

3. Install dependencies in the relevant project folders.

4. Configure the required environment variables for the backend, database connection, and Stripe integration.

5. Start the backend, frontend, and admin applications using their respective development scripts.

> **Note:** Environment variable names and available scripts depend on the configuration files in each project folder.

## 🔐 Security

- Keep API keys, database credentials, Stripe secret keys, and other sensitive environment variables private.
- Never commit `.env` files or production credentials to the repository.
